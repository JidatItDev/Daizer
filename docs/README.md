# Daizer Docs App

This directory now contains:

- Markdown documentation content (`admin-dashboard`, `user-dashboard`)
- A Vite-powered UI documentation site using **VitePress**

## Start Local UI

```bash
cd docs
pnpm install
pnpm docs:dev
```

## Build and Preview

```bash
cd docs
pnpm docs:build
pnpm docs:preview
```

## Main Entry Page

- `index.md` (title page with links to Admin and User dashboard docs)
